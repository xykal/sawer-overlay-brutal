CARA EDIT DARI BUBBLE MENU
1. Tap bubble kecil S (48px) di kiri/kanan
2. Menu muncul — drag header hitam buat geser menu enak
3. List teks overlay muncul dengan tombol EDIT / HAPUS / STYLE
4. Klik EDIT → balik ke app editor lengkap
5. Klik HAPUS → langsung hapus teks
6. Klik STYLE BOX/TAPE/HITAM → ganti style langsung
7. Drag menu via header biar gak nutupin TikTok
8. Tap overlay di layar → drag buat geser posisi teks nempel
